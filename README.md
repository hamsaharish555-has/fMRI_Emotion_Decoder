\# Explainable AI-Based fMRI Brain Decoder



\## Project Overview



This project focuses on developing an Explainable AI-based fMRI brain decoder for emotion recognition and disorder detection.



The project aims to analyze functional MRI (fMRI) brain data using Graph Neural Networks (GNNs) and explain the model's predictions using Explainable AI (XAI) techniques.



\## Objectives



\- Process and analyze fMRI brain data.

\- Build a brain connectivity graph from fMRI data.

\- Develop a Graph Neural Network (GNN) based decoder.

\- Train the model for ADHD and ASD-related analysis.

\- Provide interpretable predictions using Explainable AI techniques.

\- Visualize important brain regions and connections.
